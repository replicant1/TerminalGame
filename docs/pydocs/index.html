To regenerate after a change, from the project root:

python3 - <<'EOF' > /tmp/modules.txt
import pathlib
for p in sorted(pathlib.Path("terminalgame").rglob("*.py")):
    parts = list(p.with_suffix("").parts)
    if parts[-1] == "__init__": parts = parts[:-1]
    print(".".join(parts))
EOF
cd docs/pydocs && PYTHONPATH=../.. xargs python3 -m pydoc -w < /tmp/modules.txt

pydoc writes the absolute path of each source file into the page it makes. Those are rewritten to repository-relative links afterwards, so the pages do not name the machine they were built on and the source links work for anybody.
